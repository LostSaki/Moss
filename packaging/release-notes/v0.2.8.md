## Moss 0.2.8 (Pre-release)

**This is a beta / pre-release.** Use the **Beta** update channel to receive it. Stable stays on the last full release until we promote.

### Highlights

- Games database: known titles auto-install the Windows components they need (via winetricks)
- Broader default Visual C++ / D3D components for every game
- Stable vs Beta updates, in-app install + rollback for portable builds
- Support pack export for bug reports
- Rule-based fix suggestions after failed launches (AI advisor lands in **0.3.0**)

### Notes

- Host **winetricks** (or protontricks) is required for component auto-install
- Proton/Wine must still be installed for Play
- Deb/Flatpak installs should update via your package manager

### Downloads

Same asset matrix as 0.2.2 (AppImage, deb, Flatpak, Linux binary, Windows Setup, portable exe).
