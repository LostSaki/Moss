## Moss 0.3.0

### Highlights

- **AI log advisor** (optional): Settings → Support → enable AI suggestions, set an OpenAI-compatible endpoint and key. Failed launches send a **redacted** log excerpt (paths stripped to basenames; no API keys).
- Launch-failed dialog lists **Suggested fixes** from rules + AI, with one-click Install (winetricks) or Change EXE.
- Includes everything from **0.2.8** (games DB auto-install, Beta/Stable updates, support packs).

### Privacy

- AI is **off by default**
- Only redacted context is sent when you enable it and a launch fails (or when refreshing suggestions)
- Support packs never include your SteamGridDB / AI keys

### Downloads

Same package matrix: AppImage, deb, Flatpak, Linux binary, Windows Setup, portable exe.
