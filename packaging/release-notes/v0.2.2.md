## Moss 0.2.2

Native Linux / SteamOS launcher for Windows games (Proton/Wine). Not Lutris. Not Electron.

### Highlights

- **Scan library** — find many Windows games in a parent folder; pick what to import
- **Add this game folder** — add one specific title without scanning siblings
- Honest scan feedback when nothing is found
- Linux: **AppImage**, **.deb**, **Flatpak**, and raw binary
- Windows: **Setup installer** + portable `.exe`
- Steam Deck: run the AppImage in Desktop Mode, or add it as a Non-Steam game

### Downloads

| Asset | Platform |
| --- | --- |
| `Moss-x86_64.AppImage` | Linux / Steam Deck (recommended) |
| `moss_0.2.2_amd64.deb` | Debian / Ubuntu |
| `Moss-x86_64.flatpak` | Flatpak (`flatpak install --user Moss-x86_64.flatpak`) |
| `Moss-linux-x86_64` | Portable Linux binary |
| `Moss-Setup-0.2.2.exe` | Windows installer |
| `Moss-windows-x86_64.exe` | Windows portable |

Host Steam/Proton or Wine is still required for real gameplay on Linux.
